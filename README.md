# 蜂翼智飞 · 无人机物流配送平台

两个独立页面：

- `customer.html`：客户配送中心，支持下单、查看订单、配送跟踪、确认签收。
- `staff.html`：工作人员端，支持智能调度、拣货绑定、起飞、二次校验、允许降落。
- `screen.html`：无人机物流指挥大屏，包含核心指标、实时地图与轨迹、实时视频流、设备状态与告警，并使用 ECharts 呈现遥测趋势、Three.js/WebGL 构建 3D 数字孪生场景。

订单数据保存在浏览器本地，两个页面共用同一份数据。

## 高德地图配置

打开任意页面的右上角“地图配置”：

- 高德地图 Key：在高德开放平台创建 JS API 应用后获取。
- 安全密钥 SecurityJsCode：如果应用启用了安全密钥，填写对应的值。

保存后页面会自动加载高德在线地图；未配置时使用内置示意地图。

## WebSocket 实时数据

页面右上角“数据源”可配置 WebSocket 地址，用于推送无人机遥测和订单数据。

本地启动服务端：

```bash
cd server
npm install
npm start
```

服务端默认监听 `ws://localhost:8080`，页面数据源填写该地址即可连接。
